# <-- WITHOUT ExitOnForwardFailure, ssh just hangs here, silently useless
    
    
    
    ServerAliveInterval 30
Every 30 seconds, the SSH client sends a small encrypted "are you there?" packet to the server. This is a keep-alive probe.
Cause	Effect without keep-alive
NAT/firewall idle timeout	Drops the TCP session after N minutes of silence
Cloud load balancers	Kill "idle" connections (often 60–300s)
Docker networks / VPNs	Reap stale flows
Wi-Fi sleep / laptop suspend	Connection hangs, never recovers
Because a -N tunnel sends no data when unused, firewalls see it as "idle" and close it. The periodic probe keeps the path marked "active."
    
    
    ServerAliveCountMax 3
This is the failure threshold for ServerAliveInterval. SSH tolerates up to 3 consecutive missed probes before it gives up.
